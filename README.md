## Regenerating the Client

When the IGVF Catalog API spec changes, regenerate the Python client with these steps:

### 1. Download the latest OpenAPI spec

```bash
curl -o openapi_spec.json https://api.catalogkg.igvf.org/openapi
```

### 2. Remove unwanted endpoints and fix spec errors

```bash
python scripts/remove_endpoints.py
```

This removes `/health` and `/autocomplete` endpoints and fixes the `/llm-query` `aql_result` array missing its `items` schema. Edits `openapi_spec.json` in place.

### 3. Preprocess the spec to extract inline schemas

```bash
python scripts/preprocess_spec.py
```

The catalog API spec defines all schemas inline (no `components/schemas`), causing the generator to create models with long path-encoded names like `ComplexesFromProteins200ResponseInnerLinkedFeaturesInner`. This script extracts inline schemas into `components/schemas` with short, domain-meaningful names.

It runs two passes:
- **Object extraction**: Fingerprints all inline `type: object` schemas structurally, groups duplicates, assigns names (semantic table for common entities like `Gene`, `Protein`, `OntologyTerm`, or derived from field/operationId), and extracts bottom-up (deepest first so parent schemas reference children by `$ref`).
- **Wrapper extraction**: Finds remaining inline schemas that would generate verbose names -- `anyOf` wrappers at response `items` level, nested `anyOf` inside component properties, and array properties with complex items -- and extracts them as named components.

Reads `openapi_spec.json`, writes `openapi_spec_processed.json`.

### 4. Generate the Python client

```bash
npx @openapitools/openapi-generator-cli generate \
  -i openapi_spec_processed.json \
  -g python \
  --additional-properties useOneOfDiscriminatorLookup=true,autosetConstants=true,packageName=igvf_catalog_client,packageVersion="1.2.0" \
  --openapi-normalizer SET_TAGS_FOR_ALL_OPERATIONS=Igvf \
  --git-user-id="IGVF-DACC" \
  --git-repo-id="igvf-catalog-python-client"
```

To do a clean regeneration, remove old generated files first:

```bash
rm -rf igvf_catalog_client/ docs/ test/ .openapi-generator/
```

### 5. Verify

```bash
pip install -e .
python -c "from igvf_catalog_client import IgvfApi; print('OK')"
pytest test/
```
